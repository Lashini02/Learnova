# Learnova - Student Learning & Task Organizer

Creative Flutter mobile app project based on the provided Learnova assignment brief.

## Includes
- Splash, Login, Sign Up, Forgot Password
- Home Dashboard
- Profile Management
- Course Management
- Task & Assignment Management
- Study Planner & Schedule
- Progress & Performance Tracking
- Notifications & Settings
- Help, Feedback, Goals, Charts-style UI

## How to run
```bash
flutter pub get
flutter run
```

This version uses dummy/local UI data, so it runs without Firebase setup.
